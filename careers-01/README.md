# Offres par équipe

Postes groupés par équipe avec lieu, contrat et candidature spontanée.

## Installation

1. Aucun composant Shadcn n'est requis, seulement `symfony/ux-icons`.

2. Copiez `templates/components/Blocks/Careers01.html.twig` dans `templates/components/Blocks/`.

## Utilisation

```twig
<twig:Blocks:Careers01 />
```

Chaque texte est une prop : surchargez-la (`title="..."`) ou remplacez un `{% block %}` pour changer le contenu.
