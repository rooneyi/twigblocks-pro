# Grille de portraits

Petits portraits carrés pour une équipe plus large.

## Installation

1. Aucun composant Shadcn n'est requis, seulement `symfony/ux-icons`.

2. Copiez `templates/components/Blocks/Team08.html.twig` dans `templates/components/Blocks/`.

## Utilisation

```twig
<twig:Blocks:Team08 />
```

Chaque texte est une prop : surchargez-la (`title="..."`) ou remplacez un `{% block %}` pour changer le contenu.
