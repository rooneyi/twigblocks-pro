# Articles à la une

Deux articles à grande couverture et une grille « Plus d’articles » à bordures fines.

## Installation

1. Aucun composant Shadcn n'est requis, seulement `symfony/ux-icons`.

2. Copiez `templates/components/Blocks/Blog03.html.twig` dans `templates/components/Blocks/`.

## Utilisation

```twig
<twig:Blocks:Blog03 />
```

Chaque texte est une prop : surchargez-la (`title="..."`) ou remplacez un `{% block %}` pour changer le contenu.
