# Cartes photo

Portraits en noir et blanc qui reprennent leurs couleurs au survol.

## Installation

1. Aucun composant Shadcn n'est requis, seulement `symfony/ux-icons`.

2. Copiez `templates/components/Blocks/Team04.html.twig` dans `templates/components/Blocks/`.

## Utilisation

```twig
<twig:Blocks:Team04 />
```

Chaque texte est une prop : surchargez-la (`title="..."`) ou remplacez un `{% block %}` pour changer le contenu.
