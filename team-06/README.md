# Polaroïds et chiffres

Texte, chiffres clés et photos d’équipe inclinées façon polaroïd.

## Installation

1. Aucun composant Shadcn n'est requis, seulement `symfony/ux-icons`.

2. Copiez `templates/components/Blocks/Team06.html.twig` dans `templates/components/Blocks/`.

## Utilisation

```twig
<twig:Blocks:Team06 />
```

Chaque texte est une prop : surchargez-la (`title="..."`) ou remplacez un `{% block %}` pour changer le contenu.
