# Moments d’équipe

Temps forts de l’année et collage de polaroïds.

## Installation

1. Aucun composant Shadcn n'est requis, seulement `symfony/ux-icons`.

2. Copiez `templates/components/Blocks/Team07.html.twig` dans `templates/components/Blocks/`.

## Utilisation

```twig
<twig:Blocks:Team07 />
```

Chaque texte est une prop : surchargez-la (`title="..."`) ou remplacez un `{% block %}` pour changer le contenu.
